# Better Spreadsheet

A modern take on spreadsheets that keeps the flexibility of traditional spreadsheet
applications while adding better structure, organization, queries, dashboards, offline
support, and cloud sync.

> **Work in progress:** Better Spreadsheet is currently under active development. The
> application available below is an early development build and does not yet represent
> the complete feature set.

## Live Application

The latest version of the `main` branch is automatically deployed to GitHub Pages.
